## Dependencies

If this plugin depends on external Python libraries, declare them in **plugin.json**.

Example:

```json
{
    "dependencies": [
        {
            "name": "sqlparse",
            "version": ">=0.5.0"
        }
    ]
}
```

Entropy manages plugin dependencies through the **Extension Manager**.

Currently, Entropy **does not install packages directly from PyPI using `pip`**. Instead, dependencies are installed from offline wheel (`.whl`) packages.

### List installed extensions

```bash
ent extension list
```

### Install an extension

Copy the required wheel file into:

```text
~/.entropy/extensions/wheels
```

Then install it:

```bash
ent extension install <extension-name>
```

### Uninstall an extension

```bash
ent extension uninstall <extension-name>
```

### Download an extension

If the machine has Internet access, Entropy can download a wheel package automatically.

```bash
ent extension download <extension-name>
```

## Development Notes

- Keep `execute()` focused on orchestration.
- Encapsulate implementation details in private methods.
- Use `self.activity()` to report long-running operations.
- Use `self.message.info()`, `self.message.success()`, `self.message.warning()`, and `self.message.error()` for runtime messages.
- Use `self.ui.panel()` and `self.ui.table()` for rich output.
- Record workflow outputs in `self.outputs`.
- Register generated files in `self.artifacts`.
